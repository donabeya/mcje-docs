# ワールド移行のタスク

- 現ワールドに飽きているかのアンケート
    - 全員が飽きたと回答した場合、ワールドを作り変える

- neoforgeでのcreate modおよび関連MOD調査
- 組作り
- discordサーバのオープン化
- modrinthのクライアントアプリ導入（modの導入障壁を下げる）
- ワールド生成（LXC container）


# 既存鯖との変更点

## 組制度
- サーバー参加後に既存の組に参加
    - どの組に所属するかは、鯖主とのヒアリングを通じて行います
- 組専用VCとテキストチャット
- 申し出があれば独立して組を立てることも可能
- 組に関する制限（同じ組で集まって拠点を作らなければならないなど）は特になし

## 公開Discordサーバー
- Discordサーバー自体を移行し、公開
    - サーバー参加への障壁を取り払うことを目的としています

- ただし、Minecraftサーバーのホワイトリスト制は存続
    - Minecraft関連のチャンネルは鍵付き

## MODローダーの変更
- MODローダーに`neoforge`を採用
- クライアントMODの導入・管理は`modrinth`のクライアントソフトウェアを採用

## GitHub Organization
- GitHub Organizationを作成
- マイクラワールド外で何かしらのツール開発やドキュメント管理などに使用
